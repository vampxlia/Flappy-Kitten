# Flappy Kitten

> A desktop game inspired by Flappy Bird, made with LibGDX.

[demo.webm](https://github.com/user-attachments/assets/e8edfb7d-74dc-4f16-afee-7d4ebe570d1a)

---

## Features

- **Main Game Loop:** Fully functional game loop where the player is tasked to dodge obstacles for as long as possible.
- **Custom Assets and Music:** Game Assets, font and Music were made uniquely for the game.
- **High Score Persistence:** High Score stored through XML, allowing it to remain persistent between sessions.
---

## Tech Stack

`Java`

`Gradle`

`LibGDX`

`XML`

---

## Prerequisites

Ensure you have the following installed on your machine before running the application:
- **Java** or **Java Development Kit** version 21 or higher

---

## Getting Started & Setup Instructions

To run the game simply download and execute the .jar file [here](https://github.com/vampxlia/Flappy-Kitten/releases/latest).

If you want to compile the game yourself, you can also run the following command on the repository root instead:

```bash
./gradlew run
```

### Controls

`Spacebar` - Jump

`Escape` - Pause / Unpause
